# Verdant Kingdom / 緑の王国

一人称で探索する、オリジナルの草原アクションゲーム。任天堂の抽出素材は使用していません。バックエンド、アカウント、API キーは不要です。

## 起動

Node.js 22.12 以降（この環境では 24.19.0）。

```sh
npm ci --cache /workspace/.npm-cache
npm run dev
```

Chrome / Edge のデスクトップで開き、「冒険をはじめる」をクリックします。マウス操作には Pointer Lock と WebGL2 が必要です。開発サーバーはポート 5173、全インターフェースにバインドします。

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 |
| 視点 | マウス |
| ジャンプ | Space |
| ダッシュ | Shift |
| ポーズ / マウス解放 | Esc |
| ゲーム終了後の再挑戦 | R |

浮遊コインをたどって、草原の奥の旗に到達するとクリア。敵には上から着地すると踏みつけて跳ねます。横から接触すると失敗。ブロックは真下からジャンプして叩きます。黄色はコイン、レンガは破壊できます。3 か所の谷は走ってジャンプしてください。落下・被ダメージ後は再挑戦できます。

## 実装

- Vite / React / TypeScript、Three.js / React Three Fiber / Drei
- Rapier の固定地形、カプセル型プレイヤー、連続衝突判定、土管・ブロック・丘の衝突
- 加速、重力、接地判定、コヨーテタイム、空中操作、頭上のブロックとの衝突
- 一人称の視点、カメラの歩行・着地・ダッシュ動作、赤い袖と白い手袋
- 巡回する敵、踏みつけ、接触ダメージ、スコアとコイン、ゴール、ポーズ、再挑戦
- 約 330 m の草原、コイン 92 個、39 個のブロック、12 体の敵、12 本の土管
- 金属の土管、生成されたアルベドとバンプマップ、環境反射、太陽光、接地影、大気遠近
- インスタンシングによる草・葉・花・コイン、風の草アニメーション、破片・土埃・コイン粒子
- Web Audio で生成した取得・ジャンプ・踏みつけ・ゴールの効果音
- High / Balanced の切り替え（ピクセル比、影、草の密度）
- 実行時に外部アセットへのリクエストはありません

## 検証

```sh
npm run build
npm test
```

Playwright はデフォルトで `/usr/bin/chromium` を使います。別の環境では `CHROMIUM_PATH=/path/to/chromium npm test` を指定するか、Playwright の Chromium をインストールして設定を変更してください。テストは実際の WebGL 描画、キー操作、Rapier の衝突、ゲームの状態遷移を確認します。遠隔地点の検証には開発ビルド限定の `window.__kingdom` テストフックを使います。本番ビルドにはフックを登録しません。テストのスクリーンショットは `test-results/` に出力されます。
